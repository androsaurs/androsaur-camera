# mobile-ledger

Документ-камера для paper-ledger. Телефон на штативе показывает превью в
браузере и по команде делает фотографию A4. Пользователь работает на компьютере;
mobile-ledger не управляет документами и процессами их обработки.

Требования и проект архитектуры: [docs/SPEC.md](docs/SPEC.md).

Статус: реализован локальный Android-прототип — CameraX, фоновая служба,
HTTP-сервер, браузерный пульт, JPEG и подтверждение доставки. Интеграция с
paper-ledger, QR-привязка и серверная ретрансляция ещё не реализованы.

MCP-сервер для ИИ-агента встроен в приложение (`POST /mcp`: снимки по
хэндлам, метрики качества, просмотр и «лупа», ссылки для передачи оригинала
без токенов), см. [docs/PROTOTYPE.md](docs/PROTOTYPE.md).

Сборка, API и ограничения: [docs/PROTOTYPE.md](docs/PROTOTYPE.md).
Результаты проверок: [docs/VERIFICATION.md](docs/VERIFICATION.md).
Скорость превью и съёмки, методика и результаты замеров:
[docs/PERFORMANCE.md](docs/PERFORMANCE.md).
Целевое устройство — Xiaomi Redmi 12, Android 15. APK установлен вручную,
9 сквозных проверок камеры через Wi-Fi прошли и с выключенным экраном,
включая освобождение и повторное открытие камеры. Снимки 4080×3060 (12,5 Мп).
Раньше установка по USB блокировалась настройками Xiaomi; 2026-10-23
`adb install -r` прошёл, при блокировке APK кладётся в «Загрузки» и ставится
из проводника.
