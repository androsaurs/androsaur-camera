# androsaur-camera

Документ-камера для paper-ledger. Согласованные требования — docs/SPEC.md,
состояние прототипа и команды — docs/PROTOTYPE.md.

- Kotlin/Compose/CameraX на Android; транспортная логика и состояния запроса
  в KMP shared. Будущая iOS-камера — отдельная платформенная реализация.
- androsaur-camera не управляет документами, страницами, OCR и рабочим сценарием.
  Файл получает запросившая вкладка браузера paper-ledger.
- Снимок удаляется после ACK браузера, отмены, новой команды или перезапуска
  приложения. ACK ретранслятора не равен ACK браузера.
- Исключение: снимки MCP-агента лежат в отдельном хранилище по хэндлам и не
  подчиняются правилу замены (docs/SPEC.md); ссылки `/dl/` — право доступа,
  не печатать их.
- Повтор requestId не вызывает повторную съёмку; камера не имеет очереди
  команд, занятость возвращается ошибкой. Сетевой обрыв не равен закрытию вкладки.
- Изменения транспорта не должны молча менять согласованные правила доставки.
- Конкретные сторонние библиотеки выбирать индивидуально. Не вводить HTTPS,
  облачный SDK, медиасервер или Windows-драйвер как уже согласованное решение.
- Не печатать токен локального сервера, полный URL с token fragment или
  содержимое личных фотографий в отчётах. Не сохранять пользовательские
  фотографии в коллекцию тестов без явного запроса.
- Проверки: `./gradlew :androidApp:assembleDebug :shared:jvmTest :androidApp:lintDebug`.
  `scripts/smoke.mjs` требует установленный debug APK; при нескольких
  устройствах явно задавать ANDROID_SERIAL и адрес/ADB-forward.
- Поведение эмулятора не считать подтверждением поведения Redmi 12/Android 15.
